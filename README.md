# AURUM AI V2 — Functional Foundation

This first build contains only capabilities that genuinely work now:

- Next.js + TypeScript application
- Responsive AURUM dashboard
- Browser voice recognition in supported Chrome environments
- Browser text-to-speech responses
- Natural-language objective parsing
- Preset risk controls
- Honest HOLD state when no verified market data exists
- Locked execution until a validated trade plan exists

## Not connected yet

- No live gold data
- No Wave Engine
- No Supabase authentication
- No broker API
- No live trade execution
- No claim of profit or predictive accuracy

## Put it in GitHub using GitHub Desktop

1. Clone `AurumHq/AURUM-AI-V2` in GitHub Desktop.
2. Extract this ZIP.
3. Copy every extracted file into the cloned repository folder.
4. Commit with: `Build functional AURUM foundation`.
5. Push origin.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
